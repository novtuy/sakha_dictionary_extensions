Независимое расширение для работы с большим толковым словарем якутского языка + якутские флеш-карты

## Описание (для магазинов расширений)

Якутские карточки — независимое расширение для работы с Большим толковым словарем якутского языка (igi.ysn.ru) и с флеш-картами.

Это удобный инструмент для изучения якутского языка. Расширение сочетает быстрый поиск слов в онлайн-словаре и систему карточек с интервальным повторением, чтобы легко запоминать слова и отслеживать прогресс. Подходит всем, кто изучает, хочет подкрепить слова языка народа Саха.

Что можно делать с расширением:

✦ Искать слова в словаре прямо из всплывающего окна браузера  
✦ Смотреть определения, формы слов и связанные записи  
✦ Выделять слова на любой странице и через контекстное меню отправлять их в словарь или сохранять как карточки для повторения

Карточки:

✦ Создавайте свои наборы и тренируйтесь с помощью интервального повторения для лучшего запоминания  
✦ Отслеживайте ежедневный прогресс и повторяйте слова в разных режимах: классические карточки, интеллектуальные карточки, список сохранённых слов  
✦ Перемешивайте, сортируйте, экспортируйте и импортируйте карточки — удобно управлять сохраненными словами и переносить между устройствами

Приватность:

⊗ Все данные хранятся локально в браузере и не передаются третьим лицам

Как пользоваться:

✦ Установите расширение и закрепите его на панели браузера  
✦ Введите слово, чтобы сразу увидеть его значение и формы  
✦ Или выделяйте слова на сайтах и добавляйте их в словарь через контекстное меню  
✦ Нажимайте на звездочки, чтобы отправить карточку в базу данных  
✦ Используйте режим карточек для повторения: показывайте ответы, отмечайте слова на знание/незнание и отслеживайте прогресс  
✦ Настраивайте количество карточек за сессию и режим повторения  
✦ Подсказки в полях ввода помогут быстро вводить символы якутского письма

## Инструкция

Расширение использует базу данных слов с открытого сайта  
**igi.ysn.ru/btsja**

Работа поиска слов полностью зависит от доступности этого сайта. Потеря интернет-соединения, включение VPN или сбои в работе сайта могут привести к неработоспособности поиска.

При этом все сохранённые данные (карточки, прогресс) хранятся локально в браузере и не зависят от наличия интернета.

### Поиск слов

Поиск слов осуществляется:

- через ввод в поле ввода во всплывающемся окне расширения  
- через отправку выделенного слова с помощью контекстного меню (ПКМ)

### Ввод якутских букв

Для ввода уникальных букв якутского алфавита (`Ҕ Ө Һ Ү Ҥ`) необходимо после соответствующих символов нажать клавишу `\` (обычно располагается над Enter).

> Эта клавиша экранирована и не вводится в поле ввода — она используется исключительно для ввода уникальных букв.

### Особенности базы данных igi.ysn.ru/btsja

Некоторые символы в базе данных словаря представлены латиницей  
(например: `Y`, `A`, `X`, `O` и др.), поэтому при поиске следует учитывать эту особенность.

### Сохранение карточек

После выполнения поиска в блоках с результатами справа сверху отображается иконка ⭐.  
Нажатие на неё сохраняет слово и его определение в виде карточки и добавляет их в локальную базу данных.

База данных реализована с использованием **IndexedDB**, встроенной в браузер, и позволяет хранить большое количество данных практически без ограничений.

⚠️ **Важно:**  
База данных привязана к памяти браузера. Удаление расширения или очистка данных браузера приведёт к удалению всех сохранённых карточек.

Рекомендуется заранее **экспортировать данные**, чтобы не потерять их.  
Автоматического резервного копирования не предусмотрено.

### Режимы работы

Чтобы перейти в режим карточек, нажмите кнопку в левом верхнем углу интерфейса.  
Справа сверху доступна ссылка на сайт **igi.ysn.ru/btsja**.

Расширение имеет два основных режима:

- **Режим списка** — отображаются все сохранённые слова и их определения  
- **Режим карточек** — изучение слов в формате флеш-карт  

### Режимы карточек

Карточки можно изучать в двух режимах:

#### Интеллектуальный режим

Интеллектуальный режим учитывает время повторения карточек и основан на счётчике, связанном с последовательностью чисел Фибоначчи.

- При выборе **«Знаю»**:
  - счётчик увеличивается на 1  
  - время до следующего показа = число Фибоначчи по индексу счётчика − 1  
  - последовательность:  
    `0, 0, 1, 2, 4, 7, 12, 20, 33, ...`

- При выборе **«Не знаю»**:
  - счётчик сбрасывается:
    - к `1`, если был больше 1  
    - к `2`, если был больше 2  
  - временная переменная обнуляется  

Для новых карточек:
- счётчик равен `0`  
- время повторения не уходит в отрицательные значения  

Приоритет показа карточек определяется значением временной переменной:  
чем меньше значение, тем выше приоритет.

Карточки показываются только тогда, когда их время **≤ 0**.  
Инкрементация временной переменной происходит **раз в сутки**.

#### Обычный режим

Обычный режим формирует карточки случайным образом из списка:

- не влияет на счётчики  
- не учитывает временные переменные  
- используется для свободного повторения  

Количество карточек за одну сессию можно изменить в окошке режима карточек.
